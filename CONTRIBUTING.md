# Contributing

- **Add a case:** add an entry to `code/decision/cases.json` with the answers and the label you expect, then run `python -m unittest`.
- **Add a pattern:** keep it standard-library only, add tests, and say where the control lives.
- **Fix a claim:** open a pull request and link the source.
- Describe patterns, not results. Do not add numbers you cannot source.
- Use "two-way sync". Describe restrictions as read-only access or write permissions.
- Never include credentials, customer data or internal URLs.
